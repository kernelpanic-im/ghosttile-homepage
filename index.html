GhostTile

Hide your running applications from Dock like a charm.

  • Dock is too full?
  • Don't like some Apps' icon?
  • Don't want to see some apps when press ⌘+Tab?

Just try GhostTile!

Download 2.0 Learn More

Features

  • Hide running applications from Dock. Multiple ways:

    • Drag & Drop
    • Select from /Applicaton folder
    • Click icon on Dock
  • Per app config to hide or add menubar item.
  • Per app keyboard shortcut to quick open it.
  • Notification for added Apps' Dock activities.

  • Multiple ways to quick switch back

    • Expose-like Overview
    • Click on menubar
    • Call out Quick Switch window
    • Alias folder on Dock
  • Keyboard Shortcut support.
  • Alfred v2 Workflow support.
  • Easy installation. Support sandboxed application, no on-disk modification.

Known Issues

  • Due to System Integration Protection(SIP, Rootless) on El Capitan, not support system Apps. But you can turn it off.
  • Added Apps' behavior is like those only appearing on menu bar.
  • Not support legacy GC enabled application(e.g. Proxifier / Mou)
  • Compatibility issues with Alfred v2 toggle visibility.
  • Startup at login timing issue, some app need to re-add. (e.g. Spotify)
